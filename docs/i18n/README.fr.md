# Thème MoYun 🌿

**Donnez à DeepSeek Harness une esthétique de peinture à l'encre chinoise.**

Style peinture à l'encre · Thèmes préréglés · Fond personnalisé · Effets de particules · 8 langues

> **L'encre et la beauté intemporelle.**

| 🖼️ 5 thèmes préréglés | 🎨 Fond personnalisé | 🌊 Particules d'encre | 🌏 8 langues |
|---|---|---|---|

> Pur natif · Aucune injection · Aucun patch d'installateur

</div>

## ✨ Fonctionnalités

| Fonction | Description |
|----------|-------------|
| 🏔️ **5 thèmes préréglés** | Montagnes et Pin, Jiangnan brumeux, Bambou et vent, Prunier en neige, Paysage en blanc |
| 🖼️ **Fond personnalisé** | Toute taille d'image, compression automatique |
| 🌊 **Particules d'encre** | Points d'encre, gouttelettes, scintillement flottant |
| 🎚️ **Flou d'arrière-plan** | Contrôle par curseur |
| 🌫️ **Opacité de l'arrière-plan** | Mélange avec la couleur du thème |
| 🌏 **8 langues** | 中文 · English · 日本語 · 한국어 · Español · Français · Deutsch · Русский |
| 💾 **Persistance** | Sauvegarde automatique dans IndexedDB |
| 📱 **Responsive** | Redimensionnement de fenêtre |

---

## ⚡ Installation

```sh
dsh plugin --profile web add dsh-web-theme && dsh web
```

Après installation, ouvrez **Paramètres → Thème** pour choisir.
