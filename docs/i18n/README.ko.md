# 묘운 테마 🌿

**DeepSeek Harness에 동양 수묵화의 아름다움을 더하세요.**

중국 수묵화 스타일 · 프리셋 분위기 · 커스텀 월페이퍼 · 입자 효과 · 8개 언어

> **묵묵단청, 의경유원.**

| 🖼️ 5개 프리셋 | 🎨 커스텀 월페이퍼 | 🌊 잉크 입자 | 🌏 8개 언어 |
|---|---|---|---|

> 순수 네이티브 · 인젝션 없음 · 설치기 패치 없음

## ✨ 기능

| 기능 | 설명 |
|------|------|
| 🏔️ **5개 프리셋** | 산과 소나무, 안개 강남, 대나무 바람, 눈속 매화, 수묵 여백 |
| 🖼️ **커스텀 월페이퍼** | 아무 이미지 크기나 지원, 클라이언트 측 자동 압축 |
| 🌊 **잉크 입자** | 떠다니는 잉크 점, 이슬방울, 반짝임 |
| 🎚️ **배경 흐림** | 슬라이더 조절 |
| 🌫️ **배경 투명도** | 월페이퍼와 테마색 블렌딩 |
| 🌏 **8개 언어** | 중국어·English·日本語·한국어·Español·Français·Deutsch·Русский |
| 💾 **자동 저장** | IndexedDB에 자동 저장 |
| 📱 **반응형** | 창 크기 변경 대응 |

---

## 🏔️ 프리셋 목록

| ID | 이름 | 분위기 |
|----|------|--------|
| `01` | 산과 소나무 | 멀리 있는 산과 홀로 선 소나무 |
| `02` | 안개 강남 | 물마을의 등불 |
| `03` | 대나무 바람 | 바람에 흔들리는 대나무 |
| `04` | 눈속 매화 | 눈속의 매화꽃 |
| `05` | 수묵 여백 | 여백의 미 |

```sh
dsh plugin --profile web add dsh-web-theme && dsh web
```

설치 후 **설정 → 테마**에서 선택하세요.
