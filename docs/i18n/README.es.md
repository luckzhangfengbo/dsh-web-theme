# Tema MoYun 🌿

**Dale a DeepSeek Harness una estética de pintura a tinta china oriental.**

Estilo pintura a tinta china · Temas preestablecidos · Fondo personalizado · Efectos de partículas · 8 idiomas

> **Tinta y belleza atemporal.**

| 🖼️ 5 temas preestablecidos | 🎨 Fondo personalizado | 🌊 Partículas de tinta | 🌏 8 idiomas |
|---|---|---|---|

> Nativo puro · Sin inyección · Sin parches de instalador

## ✨ Características

| Función | Descripción |
|---------|-------------|
| 🏔️ **5 temas preestablecidos** | Montañas y Pino, Jiangnan neblinoso, Bambú y viento, Ciruelo en nieve, Paisaje en blanco |
| 🖼️ **Fondo personalizado** | Cualquier tamaño de imagen, compresión automática |
| 🌊 **Partículas de tinta** | Puntos de tinta, gotas, brillo flotante |
| 🎚️ **Desenfoque de fondo** | Control deslizante |
| 🌫️ **Opacidad de fondo** | Mezcla de fondo con color del tema |
| 🌏 **8 idiomas** | 中文 · English · 日本語 · 한국어 · Español · Français · Deutsch · Русский |
| 💾 **Persistencia** | Guardado automático en IndexedDB |
| 📱 **Responsive** | Cambios de tamaño de ventana |

---

## ⚡ Instalación

```sh
dsh plugin --profile web add dsh-web-theme && dsh web
```

Después de instalar, abre **Ajustes → Tema** para elegir.
