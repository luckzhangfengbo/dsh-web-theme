# 墨韻テーマ 🌿

**DeepSeek Harness に東洋の水墨画の美しさを。**

中国水墨画スタイル・プリセット意境・カスタム壁紙・パーティクル効果・8言語対応

> **水墨丹青、意境悠远。**

| 🖼️ 5つのプリセット | 🎨 カスタム壁紙 | 🌊 墨パーティクル | 🌏 8言語 |
|---|---|---|---|

> 純粋ネイティブ・インジェクションなし・インストーラー修正なし

</div>

---

## ✨ 機能

| 機能 | 説明 |
|------|------|
| 🏔️ **5つのプリセット** | 遠山の松、烟雨の江南、竹と風、雪の梅、山水の余白 |
| 🖼️ **カスタム壁紙** | 任意サイズの画像、クライアント側自動圧縮 |
| 🌊 **墨パーティクル** | 墨点、雨粒、微光パーティクル |
| 🎚️ **背景ぼかし** | スライダーで調整 |
| 🌫️ **背景透明度** | 壁紙とテーマ色のブレンド |
| 🌏 **8言語** | 中文・English・日本語・한국어・Español・Français・Deutsch・Русский |
| 💾 **パーシステンス** | IndexedDBに自動保存 |
| 📱 **レスポンシブ** | ウィンドウリサイズ対応 |

---

## 🏔️ プリセット一覧

| ID | 名前 | 意境 |

## ⚡ インストール

```sh
dsh plugin --profile web add dsh-web-theme && dsh web
```

インストール後、**設定 → テーマ** から選択してください。
