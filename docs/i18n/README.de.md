# MoYun Thema 🌿

**Verleihe DeepSeek Harness eine ästhetische chinesische Tuschmalerei.**

Chinesischer Tuschmalerei-Stil · Voreingestellte Themen · Benutzerdefinierter Hintergrund · Partikeleffekte · 8 Sprachen

> **Tusche und zeitlose Schönheit.**

| 🖼️ 5 voreingestellte Themen | 🎨 Benutzerdefinierter Hintergrund | 🌊 Tuschpartikel | 🌏 8 Sprachen |
|---|---|---|---|

> Rein nativ · Kein Injection · Keine Installations-Patches

</div>

## ✨ Funktionen

| Funktion | Beschreibung |
|----------|-------------|
| 🏔️ **5 voreingestellte Themen** | Berge & Kiefer, Nebliges Jiangnan, Bambus & Wind, Pflaumenbaum im Schnee, Landschaft in Weiß |
| 🖼️ **Benutzerdefinierter Hintergrund** | Beliebige Bildgröße, automatische Komprimierung |
| 🌊 **Tuschpartikel** | Schwebende Tuselpunkte, Tautropfen, Funkeln |
| 🎚️ **Hintergrundunschärfe** | Schieberegler-Steuerung |
| 🌫️ **Hintergrunddeckkraft** | Mischung mit Themenfarbe |
| 🌏 **8 Sprachen** | 中文 · English · 日本語 · 한국어 · Español · Français · Deutsch · Русский |
| 💾 **Persistenz** | Automatisches Speichern in IndexedDB |
| 📱 **Responsiv** | Fenstergrößenänderungen |

---

## ⚡ Installation

```sh
dsh plugin --profile web add dsh-web-theme && dsh web
```

Nach der Installation, öffne **Einstellungen → Thema** zum Auswählen.
