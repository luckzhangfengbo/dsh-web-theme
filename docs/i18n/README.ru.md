## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🏔️ **5 предустановленных тем** | Горы и сосна, Туманный Цзяннань, Бамбук и ветер, Слива в снегу, Пейзаж в белом |
| 🖼️ **Пользовательский фон** | Любой размер изображения, автосжатие |
| 🌊 **Тушевые частицы** | Плавающие точки туши, капли, мерцание |
| 🎚️ **Размытие фона** | Регулировка ползунком |
| 🌫️ **Прозрачность фона** | Смешивание с цветом темы |
| 🌏 **8 языков** | 中文 · English · 日本語 · 한국어 · Español · Français · Deutsch · Русский |
| 💾 **Сохранение** | Автосохранение в IndexedDB |
| 📱 **Адаптивно** | Изменения размера окна |

## ⚡ Установка

```sh
dsh plugin --profile web add dsh-web-theme && dsh web
```

После установки откройте **Настройки → Тема** для выбора.
